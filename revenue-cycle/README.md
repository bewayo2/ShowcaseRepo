# Finance & Revenue Operations

A medical billing/revenue application and separate personal-finance licensing infrastructure.

## Settle
**Repository:** [bewayo2/SettleApp](https://github.com/bewayo2/SettleApp) · **Status:** Application in development; private

Revenue-cycle codebase with FastAPI services, PostgreSQL, Redis/Celery workers and Next.js frontend. Contains modules for insurance receivables, claims, payments, short pays, documents, patient follow-ups and reports. Engineering policies address tenant isolation and audit trails. Do not infer completed HIPAA compliance, unrestricted payer integrations, quantitative recoveries, or production deployment from repository code. Validate each operational assertion independently.

**Technology:** FastAPI, PostgreSQL, Redis, Celery, Next.js

## KinCFO License Server & Demo
**Repository:** [bewayo2/KinCFO](https://github.com/bewayo2/KinCFO) · **Status:** Licensing and demonstration code; private

Firebase functions and rules for a personal-finance plugin licensing flow, with a read-only fictional household demonstration. The accessible repository does not itself establish a complete consumer finance application or live bank integration.

**Technology:** TypeScript, Firebase Functions, Firestore
