## 27Readiness
**Repo:** [bewayo2/27Readiness](https://github.com/bewayo2/27Readiness) · `JavaScript` · `Public`

Cybersecurity readiness assessment tool for organisations. Guides teams through a structured self-assessment of their security posture based on ISO 27001 / NIST-aligned controls.

### What it does
- Walks organisations through key control domains (access management, incident response, data protection, etc.)
- Produces a readiness score and maturity rating per domain
- Generates a gap analysis highlighting areas below threshold
- Outputs a prioritised remediation roadmap to guide improvement before a formal audit or certification

**Stack:** JavaScript
